# Contributing

Contributions are welcome, especially falsifications.

Please keep changes small and reviewable. For a rule change, include:

1. the rule or claim being changed;
2. the failure mode or counterexample;
3. evidence, test, benchmark, or primary source;
4. the smallest proposed edit;
5. how the change could be reverted if it makes the framework worse.

A useful issue template is simply:

```text
Claim:
Why I doubt it:
Evidence/test:
Observed result:
Proposed change:
What would falsify my proposal:
```
